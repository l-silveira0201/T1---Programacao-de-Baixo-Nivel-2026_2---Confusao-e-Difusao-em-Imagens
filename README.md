## Observação 2
Para que o programa possa rodar pelos atalhos Ctrl+Shift+B e Ctrl+F5, é necessária a pasta .vscode, com arquivos .json dentro dela. No entanto, o GitHub não aceitou o upload desta pasta, dizendo que é uma pasta oculta. Então, por garantia, colocamos uma pasta nomeada como "vscode" (sem o ponto na frente). Logo, após o download, deve-se renomear esta pasta para ".vscode", que os atalhos funcionarão corretamente.
